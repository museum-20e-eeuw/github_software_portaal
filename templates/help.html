Hulp bij het softwareportaal

Projecten beheren, stap voor stap

Naar projecten

Dit portaal helpt je softwareprojecten op GitHub te bekijken, lokaal te openen en te delen. Je hoeft Git of de technische details niet te kennen: volg de knoppen en stappen op het scherm.

Bestaand project

Verder werken aan software

  1. Kies op het startscherm het project waaraan je wilt werken.
  2. Klik op Lokaal ophalen als het project nog niet op deze computer staat.
  3. Kies een bestand en open het in het programma dat erbij past.
  4. Pas het bestand aan, sla het op en sluit het. Het portaal laat daarna zien wanneer er iets is gewijzigd.
  5. Vul in het venster dat verschijnt je naam en een korte uitleg in. Het portaal stelt een volgend versienummer voor in dezelfde notatie als de huidige versie (bijvoorbeeld 1.0 wordt 1.1 en 1.2.3 wordt 1.2.4; 0.1.0 als er nog geen versie is); je kunt dit voorstel aanpassen. Klik op Bevestigen en pushen om je wijzigingen naar de standaardbranch van GitHub te sturen.

GitHub is de online plek waar de projectbestanden worden bewaard. Met bijwerken haal je nieuwere bestanden van GitHub naar deze computer; met pushen stuur je jouw opgeslagen wijzigingen terug naar GitHub.

Nieuw project

Een project starten

  1. Klik op Nieuw softwareproject.
  2. Kies een leeg Python- of Arduino-project, of maak een kopie van een bestaand project.
  3. Geef het project een naam en eventueel een beschrijving.
  4. Kies of het project alleen voor het team bedoeld is (Privé) of voor iedereen zichtbaar mag zijn (Openbaar).
  5. Klik op Project maken en naar GitHub pushen. Het portaal maakt het project op deze computer én op GitHub aan.

Een kopie begint als een zelfstandig project: wijzigingen aan de kopie veranderen het oorspronkelijke project niet.

Andere onderdelen

Wat vind je waar?

  • Repositories: alle softwareprojecten in het overzicht.
  • Issues: vragen, fouten of klusjes die bij een project horen.
  • Pull requests: voorgestelde wijzigingen die iemand eerst kan bekijken voordat ze worden samengevoegd.
  • Workflows: automatische controles of taken die bij een project horen. Als er iets misgaat, kun je de melding bekijken of de taak opnieuw starten.
Instellingen en aanmelden

Wat moet ik weten?

  • Bij Instellingen staat de map op deze computer waarin projecten worden bewaard. Je kunt de standaardmap meestal gewoon laten staan.
  • Voor toegang tot GitHub gebruikt het portaal een persoonlijk toegangstoken. Dat token wordt lokaal op deze computer in config.json bewaard. Deel het token met niemand.
  • Het logniveau bepaalt hoeveel technische informatie wordt bijgehouden. Laat dit op de standaardinstelling staan, tenzij een beheerder je iets anders vraagt.
  • De knop Hulp bovenaan deze pagina brengt je altijd terug naar deze uitleg.
