Zo gebruik je de app

  1. Log in met het GitHub-account {{ default_username }}.
  2. Plak een personal access token met repo-, org- en workflow-rechten.
  3. Kies bovenin een hoofdmenu-item.
  4. Gebruik in een softwareproject het submenu voor detailacties.
Belangrijk

Waarom via de GitHub API?

  • Alle gegevens worden rechtstreeks via GitHub API opgehaald.
  • Acties zoals issue aanmaken, sluiten, workflow rerunnen en PR mergen lopen ook via API-calls.
  • Het token wordt alleen in het geheugen van deze lokale sessie bewaard en niet naar schijf geschreven.
